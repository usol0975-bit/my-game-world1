🏆 농장 레벨
작물을 수확해서 경험치를 모으면 농장 레벨이 올라가고, 레벨이 오를 때마다 새로운 작물이 하나씩 해금돼.

🌳 반복 수확
사과나무, 소나무, 포도, 황금사과나무는 한 번 심으면 수확한 뒤 다시 자라.

🍅 토마토
토마토는 일정 시간 동안 여러 번 수확할 수 있어.

🏪 시장
시장 가격은 3초마다 변동해. 높은 가격에 판매해서 돈을 모아보자.

⚙️ 자동 기능
자동 심기, 자동 땅 구입, 자동 씨앗 구입, 자동 수확, 자동 판매를 사용할 수 있어.
